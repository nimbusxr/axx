# axx plugin for Claude Code

Skills and an MCP server that teach Claude Code to write, run and debug
[axx](https://github.com/nimbusxr/axx) acceptance tests.

```text
/plugin marketplace add nimbusxr/axx
/plugin install axx@nimbusxr
```

Requires the `axx` CLI on your PATH (`brew install nimbusxr/tap/axx`,
or see https://axx.nimbusxr.us/guides/install/).

`skills/` is generated by `go generate ./internal/skills` from the axx
binary. Do not edit it by hand. For project-specific step references
(including your custom packs), run `axx skills install` in your repository.
