# Getting help

- **Questions and ideas:** GitHub Discussions on <https://github.com/nimbusxr/axx/discussions>.
- **Bugs:** open an issue using the bug template; include `axx version --json` and
  `axx doctor --json` output.
- **"My coding agent struggled with axx":** use the *agent friction* issue template. These
  reports feed our agent evaluation suite.
- **Security issues:** see [SECURITY.md](SECURITY.md). Never report them publicly.
