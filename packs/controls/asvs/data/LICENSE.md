# OWASP Application Security Verification Standard 5.0.0

`asvs.flat.json.gz` is the file of the standard's requirements that OWASP publishes,
`5.0/docs_en/OWASP_Application_Security_Verification_Standard_5.0.0_en.flat.json` of
<https://github.com/OWASP/ASVS> at the commit of its 5.0.0 release
(`5cf9b032440be53ce345ab3c130fda46ba1ce7a2`), unmodified but gzip-compressed. The SHA-256 of
the uncompressed file is `8201b20eec2908c3380ac600c91c8ba746346fbb808859366abb232027532311`.
