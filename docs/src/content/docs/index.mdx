## For coding agents

In a project, the axx command line answers faster than this site: `axx steps` lists every step of the project's packs, a line each, and `axx steps show <id>` gives one step's documentation and examples. On this site, every page has a Markdown twin (add `.md` to its path), [llms.txt](/llms.txt) lists them, and a pack's steps are at `/references/packs/<pack>.md`.
